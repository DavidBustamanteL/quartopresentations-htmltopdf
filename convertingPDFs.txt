# Transforming the HTML doc to a PDF:

## 1. Install in the terminal:

python -m pip install playwright pymupdf beautifulsoup4
python -m playwright install chromium


## 2. Run in the terminal in the folder, after setting a name for the new PDF file:

python clickablePDFs.py "NAME.html" -o "NAME.pdf"
python clickablePDFs.py "git_github_gitlab_intro.html" -o "Introduction to Git, GitHub, and GitLab.pdf"
